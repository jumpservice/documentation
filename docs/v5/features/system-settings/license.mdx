# License

<Alert type="xpack">
  **Enterprise features** such as organizations, roles, custom appearance,
  VirtualApp, tickets, account storage, SMS, and advanced audit reports require
  a valid license. Compare editions in [Community vs
  Enterprise](/reference/compare-editions).
</Alert>

The **License** page shows the identity of the deployment and the details of the
uploaded enterprise license. Open **System Settings > License**; the page is
titled **Authorization Management**. JumpServer Community Edition runs under
GPLv3 and does not need a license file.

## Overview

| Action                  | Description                                                                                     |
| ----------------------- | ----------------------------------------------------------------------------------------------- |
| **Machine ID**          | Identifier of this deployment. Keep it available when you request or renew a license file.      |
| **Copy Machine ID**     | Copies the machine ID so that it can be sent to the vendor with a license request.              |
| **Upload License File** | Uploads a license file to this deployment, or replaces the license that is currently in effect. |

When JDMC is enabled in the deployment, selecting **License** in System Settings
opens the license management page of the Device Manager console instead, where
the Machine ID can be copied and the license file uploaded.

## Upload a license

<Steps>

<div>
  <Nav name="system-settings" />
</div>

<div>In the left menu, click **License**.</div>

<div>
  Optional: click **Copy Machine ID** and send the ID to the vendor to request a
  license file.
</div>

<div>
  Click **Upload License File** and select the license file supplied by the
  vendor.
</div>

<div>
  Wait for the page to refresh. **Corporation**, **Edition**, **Count**,
  **Generate Time**, and **Service Expiration** show the values from the
  uploaded file.
</div>

</Steps>

## License details

| Field              | Description                                                 |
| ------------------ | ----------------------------------------------------------- |
| Corporation        | Licensed organization name recorded in the license file.    |
| Edition            | Edition enabled by the license, for example **Enterprise**. |
| Count              | Maximum number of assets covered by the license.            |
| Generate Time      | Date and time when the license file was generated.          |
| Service Expiration | End date of the license service period.                     |

<Alert type="note">
  Uploading a license file replaces the current entitlement. If the service
  period has expired or the licensed count is exceeded, the features that depend
  on the license become unavailable until the license is renewed, while existing
  data is retained. Contact the vendor through **Technical consultation** when
  you need a replacement or an extension.
</Alert>
