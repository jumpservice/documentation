# RemoteApp

<Alert type="xpack">
  **Desktop RemoteApp, advanced RemoteApp, and VirtualApp** require JumpServer
  Enterprise Edition. Web-based RemoteApp access is included in Community
  Edition.
</Alert>

RemoteApp extends JumpServer beyond terminal sessions by publishing full
applications. Windows applications run on a RemoteApp machine and are delivered
to the user's browser, while Linux applications run as containers managed by the
Panda application provider.

## Overview

| Tab                   | Purpose                                                                |
| --------------------- | ---------------------------------------------------------------------- |
| RemoteApp             | Applications available for publishing, including their release status. |
| RemoteApp machine     | Windows hosts that run and publish RemoteApp.                          |
| Application providers | Panda instances that manage VirtualApp containers.                     |
| VirtualApp            | Linux application images available to users.                           |

## RemoteApp machine requirements

| Requirement       | Minimum                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------ |
| Operating system  | Windows Server 2019, Standard or Datacenter                                                      |
| CPU               | 4 cores                                                                                          |
| Memory            | 8 GB                                                                                             |
| Remote management | WinRM or OpenSSH installed and configured                                                        |
| RDS licensing     | Remote Desktop Services license installed and activated; Windows Server includes a 120-day trial |
| Network           | HTTPS access from the machine to JumpServer, needed for registration and deployment              |

## Create a RemoteApp machine

<Steps>

<div>
  <Nav name="system-settings" />
</div>

<div>In the left menu, click **RemoteApp**.</div>

<div>Open the **RemoteApp machine** tab and click **Create**.</div>

<div>
  Enter a name and the IP address or host name. Add the `rdp` protocol for user
  sessions and either `ssh` or `winrm` for management; JumpServer prefers SSH
  when both are present.
</div>

<div>
  Add at least one account in the Windows Administrators group and enable the
  privileged option for it.
</div>

<div>
  Optionally enable automatic account creation, set the number of shared
  accounts, and set the Core service address that Tinker uses.
</div>

<div>
  Configure the RDS license if you have one, otherwise keep the trial license.
  Select a zone only when zones are in use, then click **Submit**.
</div>

</Steps>

## Deploy and upload applications

<Steps>
<div>
Open the machine detail page and select the **Deploy RemoteApp machine** tab.
</div>

<div>
  In the quick update card, click **Deploy and publish** to initialize the
  machine and publish all RemoteApp.
</div>

<div>Review deployment progress and logs in the deployment history table.</div>

<div>
Open the **RemoteApp** tab, use the app market to download an application
package, and click **Upload** to add it.
</div>
</Steps>

## VirtualApp

VirtualApp uses Linux systems as application providers, which is useful for
domestic OS environments.

<Steps>
<div>
Enable VirtualApp in [Features](/features/system-settings/general/features).
</div>

<div>
  On the JumpServer host, set `PANDA_HOST_IP` to the address of the Linux
  application provider in `/opt/jumpserver/config/config.txt`, then run `jmsctl
  restart`.
</div>

<div>
  Open **Application providers** to confirm that the Panda component is
  registered, and open its detail page to inspect VirtualApp images and
  containers.
</div>

<div>
Open the **VirtualApp** tab and upload an application package. The built-in
Chrome and Firefox images are already available.
</div>
</Steps>

Users connect to VirtualApp through a Website asset and choose the virtual
application connection method in the web terminal. Panda refreshes the list of
uploaded applications every five minutes.

<Alert type="note">
  Deployment and application publishing run as tasks. Open the task page to
  follow progress, and check the machine account list if deployment fails. For
  client-side connection details, see [Client Overview](/features/client/).
</Alert>
