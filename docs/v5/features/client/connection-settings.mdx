# Connection Settings

Client settings are local to the desktop application. Open the file menu at the
top-left and select **Connection Settings**.

## User information

The user information page shows the account currently signed in to the client and
the associated account details.

![Figure 1: Client user information](/images/v5/jumpserver/client_setting_01.png)

## General

The **General** page controls:

- Interface language
- Character set
- Character terminal behavior
- Session resolution

These defaults apply to new sessions opened from the client. A session can still
have its own protocol-specific options.

![Figure 2: Client general settings](/images/v5/jumpserver/client_setting_02.png)

## Appearance

The **Appearance** page controls the client's visual theme:

- Appearance color mode
- Primary color
- Font

![Figure 3: Client appearance settings](/images/v5/jumpserver/client_setting_03.png)

## Application configuration

<VersionBadge version="5.1.0" kind="changed" />

Local applications are used for database and application connections. Configure
the executable path for each application you use. DBX
replaces DBeaver as the default remote database application, so database sessions
open in DBX unless another application is configured for that database type.

1. Open **Application Configuration**.
2. Select the application or database type.
3. Download and install the application if needed.
4. Select **Select Path** and choose the installed executable.

If an application is not installed, use the download link shown in the client, then
return and set the path.

![Figure 4: Client application configuration](/images/v5/jumpserver/client_setting_04.png)

## Session security

<VersionBadge version="5.2.0" />

The client manages the lifetime and lock behavior of signed-in sessions:

- **Maximum login lifetime** sets the longest time a session stays signed in.
  Activity does not extend it.
- **Reauthentication** is required after the lifetime expires, and optionally
  after you fully exit and reopen the client. Reauthenticate with your JumpServer
  account.
- **Idle lock** locks the client after the configured inactivity period. Enter
  your password to unlock it and continue the current work.

Site security settings are described in
[Asset connection](/features/client/asset-connection#site-security).

## Notes

- Settings apply only to the current desktop client profile, not to other users.
- Application paths must point to a local executable that the client can launch.
- If a connection method is missing, verify both the component configuration on the
  server and the local application path.
