# Help & Support

The help menu in the top navigation provides self-service support without leaving
the current page. Open it from the question-mark icon.

![Help menu](/images/jumpserver/system_help01.png)

## What the menu provides

- Links to the official documentation and product website.
- Entry points for technical support and community resources.
- The current product version and license information, useful when reporting an
  issue.

The exact entries depend on the deployment configuration and may include local
support contact details set by the administrator.

## Before contacting support

1. Note the product version from the help menu.
2. Identify the organization and the page where the issue occurs.
3. If the issue involves a session, collect the session ID and timestamp from
   **Audits > Asset Sessions**.
4. For license or feature availability questions, check **System Settings > License**
   and the edition comparison.

## Notes

- The help menu does not change platform configuration.
- Version information is more reliable than a screenshot alone when reporting a bug.
