JumpServer brings privileged access management into one place. Use this page to
find the workspace for what you need to do, whether you are setting up users and
assets, controlling access, running sessions, or reviewing audit evidence.

## Start with a task

- **Set up your first asset and connection** — [Quickstart](/quickstart)
- **Connect to an authorized asset** — [Access Assets](/features/workbench/my-assets/access-assets)
- **Review a session or command** — [Asset Sessions](/features/audits/sessions/asset-sessions)
- **Configure roles and permissions** — [Roles](/features/system-settings/general/roles)
- **Install the desktop client** — [Client Installation](/features/client/installation)
