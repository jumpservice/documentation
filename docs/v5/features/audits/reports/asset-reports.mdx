# Asset Reports

<Alert type="xpack">
**Audit reports** require JumpServer Enterprise Edition. Raw session and log evidence remains available according to your deployment configuration.
</Alert>

**Asset Reports** summarizes the asset inventory and how users connect to it. Use it to track asset growth, confirm which assets are connectable, and see how users reach assets and which operating systems they log in to.

Open the page from **Audits > Report > Asset Reports**.

## Report types

- **Asset statistics report** — inventory overview with asset type distribution and growth trend.
- **Asset activity report** — session-based view of asset usage, with user and asset activity, login entry points, protocols, operating systems, and login trends.

## Prerequisites

- A valid enterprise license. Without a license, the Report area is not available.
- An audit role with the `rbac.view_assetstatisticsreport` or `rbac.view_assetactivityreport` permission.

## Read the asset statistics report

<Steps>
<div>
Select **Asset statistics report** in the left panel.
</div>
<div>
Choose **Today**, **Last 7 days**, or **Last 30 days**.
</div>
<div>
Review the overview counters: total assets, active, connectable, linked domains, connected directory services, and platforms.
</div>
<div>
Read the **Asset type distribution** chart and the **Growth trend** chart.
</div>
</Steps>

![Figure 1: Asset statistics report with overview counters, asset type distribution, and growth trend.](/images/jumpserver/v5_admin_report_02.png)

## Read the asset activity report

Select **Asset activity report** to see usage rather than inventory. The overview shows sessions, assets, and users in the range. Charts include user/asset activity, distribution of asset login methods, remote login protocol usage distribution, operating system distribution of login assets, and asset login trends.

## Field reference

| Report | Metric or chart | Description |
| --- | --- | --- |
| Asset statistics | Total | Total assets in the organization. |
| Asset statistics | Active | Assets that are enabled. |
| Asset statistics | Connectable | Assets with at least one connectable account. |
| Asset statistics | Linked domains | Assets associated with a domain or zone. |
| Asset statistics | Connected directory services | Assets linked to a directory service. |
| Asset statistics | Platform | Number of platforms represented by the assets. |
| Asset statistics | Asset type distribution | Asset count by asset type category. |
| Asset statistics | Growth trend | Number of assets added over time. |
| Asset activity | Session / Asset / User | Sessions, distinct assets, and distinct users in the range. |
| Asset activity | User/Asset activity | Active users and active assets over time. |
| Asset activity | Distribution of asset login methods | Login entry points used to connect to assets. |
| Asset activity | Remote login protocol usage distribution | Protocols used for asset logins. |
| Asset activity | Operating system distribution of login assets | Operating systems of assets that users logged in to. |
| Asset activity | Asset login trends | Asset logins over time. |

## Notes

<Alert type="note">
**Customize** controls which charts and tables the report displays. The statistics report reflects inventory, while the activity report reflects sessions in the selected range, so the two can legitimately disagree.
</Alert>
