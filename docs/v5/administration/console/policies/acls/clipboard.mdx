# Clipboard

**Clipboard** controls whether users can copy from or paste into a connected
asset, and it can cap the amount of text and the size of files moved through the
clipboard. Rules match users, assets, and accounts, so restrictions can be
narrower than the asset authorization itself.

Open the page from **Console > ACLs > Clipboard**.

![Figure 1: Create clipboard control with operations, limits, and action.](/images/jumpserver/v5_admin_acls_08.png)

## Overview

The page title is **Clipboard Control**. Each rule selects the clipboard
operations to manage (copy, paste), optional limits, and the action applied when
the rule matches. Rules are scoped to the current organization and are evaluated
by priority, where a lower number is matched earlier.

## Before you begin

- Sign in with an account that can manage ACLs.
- Decide whether the rule should restrict copying, pasting, or both.
- If you plan to enforce limits, confirm the expected size units with the asset
  owners: text limits are measured in characters and file limits in MB.

## Create a clipboard control

<Steps>
<div>
Click **Create**.
</div>

<div>
In the **Create clipboard control** drawer, fill in the fields below.
</div>

<div>
Click **Submit**.
</div>
</Steps>

### Field reference

| Group | Field | Description |
| --- | --- | --- |
| Basic | Name | Required. Rule name, unique within the organization. |
| Basic | Priority | Integer from 1 to 100. Defaults to 50; the lower the value, the earlier the rule is matched. |
| Users | Users | **All users**, **Specified users**, or **Attribute filter**. |
| Assets | Assets | **All assets**, **Specified assets**, or **Attribute filter**. |
| Accounts | Accounts | **All accounts** or **Specified accounts**. |
| Clipboard | Operations | Select **Copy** and/or **Paste**. By default both are controlled. |
| Limit | Copy text limit | Maximum number of characters that can be copied. Defaults to 0, which means unlimited. |
| Limit | Paste text limit | Maximum number of characters that can be pasted. Defaults to 0, which means unlimited. |
| Limit | Download file size limit | Maximum file size when copying a file from the asset to the local machine, in MB. Defaults to 0, which means unlimited. |
| Limit | Upload file size limit | Maximum file size when pasting a file from the local machine to the asset, in MB. Defaults to 0, which means unlimited. |
| Action | Action | **Accept** or **Reject**. Defaults to **Accept**. |
| Other | Active | When selected, the rule takes effect. |
| Other | Comment | Optional. |

## Example configurations

| Goal | Configuration |
| --- | --- |
| Block all clipboard use on production databases | Users: specified group; Assets: production database nodes; Operations: Copy and Paste; Action: Reject. |
| Allow copied text up to 1,000 characters | Operations: Copy; Copy text limit: 1000; Action: Accept. |
| Allow small file transfers only | Download and upload file size limits: 10 MB each; Action: Accept. |

<Alert type="warning">
With **Action: Reject**, the selected operations are blocked for every matched
connection. Leave the limits at 0 only when unlimited clipboard usage is
acceptable, and test a reject rule on a small user group before enabling it
broadly.
</Alert>
