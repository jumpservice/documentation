# Storage

Storage tells JumpServer where to keep session evidence. Recordings and replay
files belong in object storage, and command records belong in command storage.
Keeping this data outside the local disk makes it possible to centralize,
retain, and scale audit evidence.

## Overview

The page has two tabs:

| Tab | Stores |
| --- | --- |
| Object storage | Session recordings and replay files for each component. |
| Command storage | Session command records generated during asset connections. |

The table on each tab lists the configured storages with their name, type,
description, default marker, and actions. A default entry is preselected for
components that register later.

## Supported types

Object storage:

| Type | Notes |
| --- | --- |
| Local | Stores recordings on the JumpServer server. |
| Null | Discards recordings. |
| Amazon S3, Ceph, Swift, Alibaba Cloud OSS, Azure Blob, Huawei Cloud OBS, Tencent Cloud COS | External object storage. Connection fields depend on the provider. |
| SFTP | Backup-only storage, for example for account backups. Cannot be set as the default object storage. |

Command storage:

| Type | Notes |
| --- | --- |
| Local | Stores command logs in the local database. |
| Null | Discards command logs. |
| Elasticsearch | External search cluster; requires the host list and index name. |

## Manage storage entries

- **Set as default**: use the more actions menu on an entry. Newly registered
  components pick up the default automatically; components that are already
  registered keep their current storage until you change them on the
  [Components](/administration/system-settings/infrastructure/components) page.
- **Test**: validates the connection and credentials without connecting a
  component.
- **Edit**: change connection details or the description.
- **Delete**: remove the entry. A storage that is still in use by a component
  should be replaced before deletion.

## Notes

<Alert type="note">
The default storage is applied to newly registered components only. SFTP object
storage requires an Enterprise license, and it can be used for backups but not
as the default recording storage.
</Alert>

<Alert type="warning">
Session recordings and command logs that are written to external storage are not
removed by the retention settings in
[System Tasks](/administration/system-settings/infrastructure/system-tasks); plan retention for the
external system separately.
</Alert>
