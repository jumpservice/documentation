# Appearance

<Alert type="xpack">
**Custom themes and logo replacement** require JumpServer Enterprise Edition. Community Edition uses the default branding.
</Alert>

Appearance changes the visual identity of this JumpServer deployment. The
settings are instance-wide: title, theme, logos, the login illustration, and
footer content are the same for every organization and every user.

## Overview

Every field on this page is optional. Empty fields keep the built-in value, and
the **Restore** button returns the entire page to the default appearance.

## Customize the appearance

<Steps>

<div>
<Nav name="system-settings" />
</div>

<div>
In the left menu, click **Appearance**.
</div>

<div>
Update the basic, logo, image, and footer settings described below.
</div>

<div>
Click **Submit**.
</div>

<div>
Reload the page to confirm the new title, logos, and login image.
</div>

</Steps>

![Figure 1: Appearance settings](/images/jumpserver/V4_appearance_01.png)

## Field reference

| Field | Description |
| --- | --- |
| Login title | Title shown on the login page and in the browser tab of the sign-in flow. |
| Theme | Color theme of the console. Available themes are Classic green (default), Chinese red, Deep black, Noble purple, and Technology blue. |
| Wide logo on top | Logo shown in the upper-left corner of the console. Recommended size: 185 × 55 px. |
| Small logo without text | Square icon shown in the web terminal. Recommended size: 82 × 82 px. |
| Website icon | Browser tab icon (favicon). Recommended size: 16 × 16 px. |
| Login image | Illustration shown to the right of the login form. Recommended size: 492 × 472 px. |
| Footer content | Markdown text displayed at the bottom of the login page, commonly used for the registration number or legal notice. |

Uploads accept JPG and PNG files. Images are stored by JumpServer and served
from the same origin as the console, so no restart is required after saving.

![Figure 2: Theme selection](/images/jumpserver/V4_appearance_04.png)

## Restore defaults

<Steps>
<div>
Open the **Appearance** page.
</div>

<div>
Click **Restore** at the bottom of the page.
</div>

<div>
Confirm the prompt. The default title, theme, logos, login image, and footer are
restored immediately.
</div>
</Steps>

<Alert type="note">
The theme choice affects the whole console. Individual display preferences, such
as language and layout, are stored per user and are configured from
[Preferences](/general/account/preferences).
</Alert>
