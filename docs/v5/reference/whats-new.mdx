# What's new in JumpServer V5

JumpServer V5 refreshes the native client, adds AI-assisted operations and
auditing, redesigns the KoKo terminal, and expands connectivity, access control,
and audit coverage. This page maps each release to the pages that describe the
capability, so you can tell which version introduced a feature and where its
behavior changed.

## How version notes work

Feature pages use three conventions to record version information:

| Convention            | Meaning                                                         | Example                              |
| --------------------- | --------------------------------------------------------------- | ------------------------------------ |
| Version badge         | The version that introduced or last changed the section         | `New in v5.1.0`, `Changed in v5.1.0` |
| Version history table | A page-level list of every version change that affects the page | `Version \| Change`                  |
| Version in prose      | A capability that only exists in some versions                  | `Available since JumpServer v5.1.0.` |

Badges mark when behavior appeared; they do not replace the edition requirement.
An Enterprise-only capability still carries an **Enterprise Edition** note. For
example, <VersionBadge version="5.1.0" /> marks a section introduced in that
release, and <VersionBadge version="5.1.0" kind="changed" /> marks a section
whose behavior changed in that release.

## v5.0.0

| Refreshed JumpServer Client with a unified entry for SSH, RDP, Kubernetes, database, and RemoteApp assets, split views, a file workspace, a script library, and SFTP Server connections | [Client](/user-guide/client/), [Workspace, files, and scripts](/user-guide/client/workspace)                |
