# Import license <Icon name="xpack-lg" />

<Alert type="xpack">
  Importing a license file is available in JumpServer Enterprise Edition only.
  Compare editions in [Community vs Enterprise](/reference/compare-editions).
</Alert>

This topic describes how to import the license for the enterprise edition of JumpServer.

<Steps>

<div>
  <Nav name="system-settings" />
</div>

<div>
Navigate to the **System settings > License**.
</div>

<div>
  In the "Quick update" section on the right side of the page, locate the
  "Import license" option and click the "Import" button.
  <img
    src="/images/docs/admin-guides/system-settings/license/import-license.png"
    alt="Figure 1: Import license option in System Settings"
    width="450"
  />
</div>

<div>
  In the "Import license" dialog box, click the "Choose file" button to select
  the license file.
</div>

<div>Click **Confirm**.</div>

</Steps>
