# Upload license <Icon name="xpack-lg" />

This topic describes how to upload a license file for JumpServer Enterprise
Edition. Community Edition deployments run under GPLv3 and cannot upload a
license.

<EnterpriseEditionCta />

<Steps>

<div>
  <Nav name="system-settings" />
</div>

<div>
  Navigate to **System Settings > License**. The page is titled **Authorization
  Management**.
</div>

<div>
  Optional: click **Copy Machine ID** to copy the deployment ID when the vendor
  asks for it during the license request.
</div>

<div>
  Click **Upload License File** and select the license file supplied by the
  vendor.
</div>

<div>
  Wait for the page to refresh. Verify **Corporation**, **Edition**, **Count**,
  **Generate Time**, and **Service Expiration** against the license you
  received.
</div>

</Steps>

<Alert type="note">
  Uploading a license file replaces the current entitlement. If the service
  period has expired or the licensed count is exceeded, the features that depend
  on the license become unavailable until the license is renewed, while existing
  data is retained.
</Alert>
