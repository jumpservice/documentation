# Upgrade

This topic describes how to upgrade JumpServer, including both the open-source and enterprise editions.

<Alert>
We recommend upgrading JumpServer regularly to access the latest designs and features.
</Alert>

## Upgrade for one-line installation

If you have installed JumpServer using the [Install with a one-line command](/docs/installation#install-with-a-one-line-command) guide, you can upgrade JumpServer by running the following steps.

<Steps>

<div>
Log in to the JumpServer deployment server using the "root" or another user with superuser privileges.
</div>

<div>
Change to the `/opt` directory.
</div>

<div>
Download the latest installation package.
```sh
wget https://github.com/jumpserver/installer/releases/download/v4.10.19/jumpserver-installer-v4.10.19.tar.gz
```
</div>

<div>
Extract the installation package.
```sh
tar -zxvf jumpserver-installer-v4.10.19.tar.gz
```
</div>

<div>
Change to the extracted directory.
```sh
cd jumpserver-installer-v4.10.19
```
</div>

<div>
Perform the upgrade.
```sh
./jmsctl.sh upgrade
```
</div>

<div>
Start all services.
```sh
./jmsctl.sh start
```
</div>

<div>
At this point, you have successfully upgraded JumpServer.
</div>

</Steps>

## Upgrade for offline installation

If you have installed JumpServer using the [Install with an offline package](/docs/installation#install-with-an-offline-package) guide, you can upgrade JumpServer by running the following steps.

<Steps>

<div>
Log in to the JumpServer deployment server using the "root" or another user with superuser privileges.
</div>

<div>
Change to the `/opt` directory.
</div>


<div>
Download the JumpServer Enterprise offline installation package.


<Tabs
  titlesMap={{
    web: "Web",
    wget: "wget",
  }}
>
  <Tab titleKey="web">
    <Steps stepLevel="2">
      <div>
      Log in to https://support.fit2cloud.com using the username and password provided by the support team.
      </div>

      <div>
      View the details of your valid Enterprise Edition subscription and navigate to the 'Installation Packages' tab. Find the installation package that matches your required version and architecture, click the 'Download' button, and then click 'Download' in the pop-up dialog to copy the download link.
      </div>

      <div>
      Upload the offline installation package to the `/opt` directory on the deployment server.
      </div>
    </Steps>
  </Tab>

  <Tab titleKey="wget">
    <Steps stepLevel="2">
      <div>
      Log in to https://support.fit2cloud.com using the username and password provided by the support team.
      </div>

      <div>
      View the details of your valid Enterprise Edition subscription and navigate to the 'Installation Packages' tab. Find the installation package that matches your required version and architecture, click the 'Download' button, and then click 'Copy Link' in the pop-up dialog to copy the download link.
      </div>

      <div>
      Replace the download link and run the following command to download the offline installation package.
      ```sh
      cd /opt && wget -O jumpserver-ee-v4.10.19-x86_64.tar.gz "https://support.fit2cloud.com/download/00000000-0000-0000-0000-00000000000/jumpserver-ee-v4.10.19-x86_64.tar.gz"
      ```
      </div>
    </Steps>
  </Tab>
</Tabs>

</div>
<div>
Extract the installation package.
```sh 
tar -zxvf jumpserver-ee-v4.10.19-x86_64.tar.gz
```
</div>

<div>
Change to the extracted directory.
```sh
cd jumpserver-ee-v4.10.19-x86_64
```
</div>

<div>
Perform the upgrade, the upgrade process can be completed using all default options.

```sh
./jmsctl.sh upgrade
```

</div>

<div>
Start all services.
```sh
./jmsctl.sh start
```
</div>

<div>
At this point, you have successfully upgraded JumpServer.
</div>

</Steps>
