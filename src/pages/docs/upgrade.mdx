# Upgrade

This topic describes how to upgrade JumpServer, including both the open-source and enterprise editions.

<Alert>
We recommend upgrading JumpServer regularly to access the latest designs and features.
</Alert>

## Upgrade for one-line installation

If you have installed JumpServer using the [Install with a one-line command](/docs/installation#install-with-a-one-line-command) guide, you can upgrade JumpServer by running the following steps.

<Steps>

<div>
Log in to the JumpServer deployment server using the "root" or another user with superuser privileges.
</div>

<div>
Change to the `/opt` directory.
</div>

<div>
Download the latest installation package.
<VersionedCommand template="wget https://github.com/jumpserver/installer/releases/download/{version}/jumpserver-installer-{version}.tar.gz" />
</div>

<div>
Extract the installation package.
<VersionedCommand template="tar -zxvf jumpserver-installer-{version}.tar.gz" />
</div>

<div>
Change to the extracted directory.
<VersionedCommand template="cd jumpserver-installer-{version}" />
</div>

<div>
Perform the upgrade.
```sh
./jmsctl.sh upgrade
```
</div>

<div>
Start all services.
```sh
./jmsctl.sh start
```
</div>

<div>
At this point, you have successfully upgraded JumpServer.
</div>

</Steps>

## Upgrade for offline installation

If you have installed JumpServer using the [Install with an offline package](/docs/installation#install-with-an-offline-package) guide, you can upgrade JumpServer by running the following steps.

<Steps>

<div>
Log in to the JumpServer deployment server using the "root" or another user with superuser privileges.
</div>

<div>
Change to the `/opt` directory.
</div>


<div>
Download the JumpServer Enterprise offline installation package.


<Tabs
  titlesMap={{
    web: "Web",
    wget: "wget",
  }}
>
  <Tab titleKey="web">
    <Steps stepLevel="2">
      <div>
      Log in to the offline package download site provided by the delivery team.
      </div>

      <div>
      Find the JumpServer Enterprise package for your required version and architecture, then download it.
      </div>

      <div>
      Upload the offline installation package to the `/opt` directory on the deployment server.
      </div>
    </Steps>
  </Tab>

  <Tab titleKey="wget">
    <Steps stepLevel="2">
      <div>
      Log in to the offline package download site provided by the delivery team.
      </div>

      <div>
      Find the JumpServer Enterprise package for your required version and architecture, then copy its download link.
      </div>

      <div>
      Replace `YOUR_DOWNLOAD_URL` with the copied link, then run the following command to download the offline installation package.
      <VersionedCommand template={'cd /opt && wget -O jumpserver-ee-{version}-x86_64.tar.gz "YOUR_DOWNLOAD_URL"'} />
      </div>
    </Steps>
  </Tab>
</Tabs>

</div>
<div>
Extract the installation package.
<VersionedCommand template="tar -zxvf jumpserver-ee-{version}-x86_64.tar.gz" />
</div>

<div>
Change to the extracted directory.
<VersionedCommand template="cd jumpserver-ee-{version}-x86_64" />
</div>

<div>
Perform the upgrade, the upgrade process can be completed using all default options.

```sh
./jmsctl.sh upgrade
```

</div>

<div>
Start all services.
```sh
./jmsctl.sh start
```
</div>

<div>
At this point, you have successfully upgraded JumpServer.
</div>

</Steps>
