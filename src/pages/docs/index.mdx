# Introduction

Note: JumpServer documentation is continually being updated. Please stay tuned for more details.


## About JumpServer

JumpServer is an Open-source Privileged Access Management (PAM) platform with AI-powered capabilities, providing DevOps and IT teams a unified workspace to securely access SSH, RDP, Kubernetes, databases, websites, RemoteApp, VirtualApp, and more.

<br/>

## About Components

JumpServer consists of multiple key components, which collectively form its functional framework and provide capabilities for operations management and security control.
